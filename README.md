# Галерея фотографий

Статический адаптивный шаблон галереи фотографий по заданию [verstaem.online](https://verstaem.online/tasks/galereya-fotografij).

## Функционал

- вывод шести карточек фотографий с названием и датой;
- адаптивная сетка: 3 колонки на десктопе, 2 на планшете, 1 на мобильных устройствах;
- hover-состояние кнопки «Загрузить».

Кнопка загрузки не подключена к обработчику и пока не загружает файлы.

## Стек

- HTML5;
- CSS3 (Grid, media queries, `@font-face`);
- локальный шрифт Inter;
- PNG-изображения;
- JavaScript, фреймворки, база данных и API отсутствуют.

## Запуск

`package.json` отсутствует, поэтому установка зависимостей и npm-команды не требуются.

Откройте `index.html` в браузере или запустите его через любое расширение локального сервера в VS Code.

## Структура

```text
index.html       # разметка галереи
css/style.css    # стили и адаптивная сетка
img/             # фотографии галереи
fonts/           # локальные файлы Inter
verstaem.json    # идентификатор задания
```
